# Accident Severity Prediction App

A Python machine learning project focused on predicting road traffic accident severity.

## Overview

This project explores the use of machine learning to analyze road traffic collision data and estimate accident severity from available input features.

The broader motivation is to investigate how data-driven models can support road safety analysis and help identify patterns associated with collision outcomes.

## Getting Started

### Prerequisites

- Python version compatible with the project
- pip

### Installation

```bash
git clone https://github.com/paschal1/Accident-Severity-Prediction-App.git
cd Accident-Severity-Prediction-App
```

Create and activate a virtual environment.

On Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

On macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies if the repository contains a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

Run the application using the entry point configured in the project. Document the exact command once the entry point and framework have been confirmed.
